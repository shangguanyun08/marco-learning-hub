# Focused words: review and adaptive recall

299 stable words in six sections (50 × 5 + 49). The original selection was 259 explicit unknowns and 36 responses needing another try from the 425-word review. MIRTH, DOUSE, PERPETUAL, and IMPENETRABLE were later added to Section 6. Word membership and section assignments are unchanged by the adaptive workflow.

Each section starts at Round 0: all its words have a short meaning, an original simple example with the exact target in bold, and a user-activated pronunciation button using browser speech synthesis when available. Round 1 recalls every word without examples. Finishing creates an immutable response copy. Round 2 contains only the explicit unknowns from Round 1, shuffled; every later round repeats only the preceding round's unknowns. There is no fixed round limit. Zero unknowns ends the section without an empty next round. Written meanings are self-reported recall, not automatically graded correctness.

Completed rounds remain visible and read-only. Each retry attempt is tied to its parent completion, so concurrent devices cannot accidentally mix retry sets. Canonical earliest completion determines the active path; alternative copies and drafts remain preserved in exports. Draft fields merge by timestamp and API saves use exact server-version checks. Empty startup is GET-only. Browser and online progress include review completion, every recall round, and legacy records.

Namespace: `marco-vr-meaning-round2-20261101-v1`. Adaptive schema version 3 uses a separate `:adaptive-v3` browser key. Earlier version 2 records remain untouched locally and are archived inside `legacyVersions`; existing first-round drafts and completed copies migrate. The older sync client rejects version 3 and performs no POST, preventing an older open tab from stripping adaptive fields. The original 425-word app is independent.

`?demo=1` disables production progress and time writes. Tests use in-memory API mocks and speech stubs. Run `node --test marco-vr-practice/meaning-check/round-2/tests.mjs` with jsdom available through NODE_PATH. Tests cover all 299 examples, pronunciation controls, Round 0, 50 → 3 → 1 retry narrowing, twelve rounds, zero-unknown completion, reloads, legacy migration, stale saves, concurrent completion branches, and old-client compatibility.
