What this course checks

Rates/proportions; graphs and data; absolute value/signs; percentages; algebra with separate conditions. Ten short foundation checks cover decimal powers, angles, and nets.

Most questions combine familiar mathematics with a changed condition, unknown, or representation. These are original practice questions inspired by recorded skill gaps—not official ISEE items or an exhaustive syllabus.

Sets 1–4 build skills. Sets 5–6 are independent mixed checks. Review past first-try mistakes after Set 6, then follow this order: Review Session 2 → Set 7 → Review Session 3 → Review Session 4 → Review Session 5 → Set 8 → Set 9 → Set 10. Review Session 3 focuses on 8 skills at 50% or lower across the latest 4 similar questions. Review Session 2 has 4 fresh questions for each of the 15 review subtopics, with a target of at least 3/4 correct on the first try. Review Session 3 has 32 fresh questions across 8 selected subtopics, with the same 3/4 first-try goal. Review Session 4 rechecks the 7 skills below 100% in Review 3 with 28 fresh questions and a 4/4 first-try target per skill. Set 7 has 20 questions and a goal of 18/20 = 90%. Sets 8–10 each have 17 fresh questions: 1 for each of the 17 skills with 4/4 recent first-try accuracy. Their goal is 16/17 = 94% correct on the first try. Use separate days for the three sets; each skill gets 3 fresh checks in total. Sets 8–10 open in order after the previous set is finished. All sets are untimed; opening a page does not start a timer.

The 90% goal uses first answers only. A finished green card means completed, not long-term mastery; written method notes are not automatically graded.

Finish your earlier sessions to unlock the next one.

Finish each core set's Round 1 and required Round 2 before opening the next core set, including the second try on missed answers in both rounds. Round 2 opens after its own Round 1 is complete and uses first-try misses with new numbers. Sets with no first-try misses need no Round 2. A perfect score is not required. The new Set 7 opens after Sets 1–6 are finished; earlier Round 2 practice does not block these new checks. Set 8 opens only after Set 7 and Review Sessions 3, 4, and 5 are finished. Finish all 32 Review 3 questions, all 28 Review 4 questions, and all 20 Review 5 questions, correcting missed answers. Review 5 must be fully corrected before either Set 8 or Set 9 can be practiced, even if the set was completed earlier. Saved answers and results are preserved. Review 4 aims for 4/4 first try in each skill; corrections do not raise the first-try score. Set 9 also requires Set 8 completion. Set 10 keeps its existing requirement to finish Set 9. Sets 7–10 allow one retry on each missed question, but have no separate Round 2. Only first answers count toward the goal: 18/20 in Set 7; 16/17 in Sets 8–10. Completed out-of-order work stays available as saved results.
