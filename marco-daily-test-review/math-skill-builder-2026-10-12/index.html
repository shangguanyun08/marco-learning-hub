What this course checks

Rates/proportions; graphs and data; absolute value/signs; percentages; algebra with separate conditions. Ten short foundation checks cover decimal powers, angles, and nets.

Most questions combine familiar mathematics with a changed condition, unknown, or representation. These are original practice questions inspired by recorded skill gaps—not official ISEE items or an exhaustive syllabus.

Sets 1–4 build skills. Sets 5–6 are independent mixed checks. Review past first-try mistakes after Set 6, then follow this order: Review Session 2 → Set 7 → Review Session 3 → Set 8 → Set 9 → Set 10. Review Session 3 focuses on Review 2 subtopics at 50% or lower. Review Session 2 has 4 fresh questions for each of the 15 review subtopics, with a target of at least 3/4 correct on the first try. Review Session 3 has 24 fresh questions across 6 selected subtopics, with the same 3/4 first-try goal. Set 7 has 20 questions and a goal of 18/20 = 90%. Sets 8–10 each have 12 questions, with 2 questions per Review 3 target subtopic. Their goal is 11/12 = 92% correct on the first try. Sets 8–10 open in order after the previous set is finished. All sets are untimed; opening a page does not start a timer.

The 90% goal uses first answers only. A finished green card means completed, not long-term mastery; written method notes are not automatically graded.
