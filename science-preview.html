Assessment practice

Think first. Review after.

  1. All 21 questions appear on one page. Choose an answer and press Check answer for each question. Scroll or use the question navigator, and flag questions for review.
  2. Green means correct first try, red means incorrect, and yellow means corrected. Full explanations appear when you finish.
  3. Review the evidence and reasoning behind each correct answer.

The score uses your first checked response on each item. Finishing records any unchecked selection as its first try. Corrections never add first-try points. Each question has one best answer and earns one point when correct. Unanswered items earn zero.
