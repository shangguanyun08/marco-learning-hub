# Marco R2 · Missed-Word Mastery

A static GitHub Pages practice site containing the 249 unique words Marco missed in the first round of the 600-word Round 1 course.

- five R2 sessions (50, 50, 50, 50, and 49 words)
- answers lock after the first choice
- instant feedback
- only misses advance to the next mastery round
- every answer and finished round uploads to the shared online record
- the Results screen refreshes automatically across devices
- `localStorage` remains an offline safety copy

## Verify locally

```bash
npm test
npx serve .
```
